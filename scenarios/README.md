# Scenarios

Each `.json` here is a scenario the simulator replays. The narrative lives in **data, not code** — add or edit a file to change the demo story; it auto-appears in the UI dropdown.

Shape: each file has a `scenario_id`, a `persona` block (the canonical patient is
**Eleanor**, 70 — see `data/personas/eleanor.md`), a `context`, and a `timeline`
of events. Mirror an existing file to add a new one.

- `heat_warning_eleanor.json` — HERO (record this one)
- `silent_morning.json` — BACKUP (no civic data dependency)
